# Liquid Material

> HaloUI's material system defines how translucent surfaces receive light, separate from their environment, express depth, and respond to interaction.

Liquid Material is not a single glass effect. It is a coordinated system of surface tint, optical edges, directional highlights, background diffusion, restrained refraction, contact shadows, texture, elevation, and motion.

Components use different combinations of these properties according to their role. A dense form control should not have the same optical intensity as a floating showcase surface.

## Material model

HaloUI treats a component surface as a layered optical material rather than a transparent container with blur applied behind it.

The material model separates responsibilities that are often combined into one CSS declaration. Surface color establishes the material body. Edges define thickness and separation. Highlights communicate incoming light. Diffusion controls background clarity. Refraction introduces restrained optical displacement. Shadows communicate contact and elevation.

No individual layer defines HaloUI. The identity comes from how the layers cooperate.

| Ordinary glass treatment | HaloUI Liquid Material |
| --- | --- |
| Transparency as the primary effect | Surface tint is part of a broader material model |
| Uniform border | Direction-aware optical edge |
| Backdrop blur defines the material | Diffusion is only one material property |
| Generic drop shadow | Contact and ambient shadows have separate roles |
| Static appearance | Selected surfaces can respond to interaction and environment |
| Same treatment across components | Material intensity changes by component role |
| Visual effect first | Behavior, readability, and accessibility remain primary |

## Surface

The surface is the material body of a HaloUI component. It establishes tint and transparency before diffusion, highlights, shadows, or interaction effects are applied.

A surface should never become so transparent that the component loses visual ownership of its content. Surface treatment depends on theme, environment, elevation, component role, and material intensity.

Surface tint prevents translucent components from behaving like unbounded windows into the background. It gives the material a stable body while allowing environmental information to remain visible.

Light theme uses a restrained luminous neutral tint (`rgba(255, 255, 255, 0.72)`). Dark theme uses a deep graphite tint (`rgba(22, 23, 26, 0.7)`).

## Optical edge

The optical edge describes where the material ends and the surrounding environment begins.

Unlike a conventional uniform border, a HaloUI edge responds subtly to the virtual light direction. Portions facing the light appear slightly brighter while opposing edges remain quieter, grounding the surface against its substrate.

Directional edge treatment must remain subtle enough that the component still reads correctly when the effect is unavailable.

## Highlights

Highlights communicate the relationship between a surface and the virtual light source. HaloUI uses three distinct highlight tiers:

### Broad highlight

A low-frequency light region that helps establish the overall orientation of a surface. Reserved for larger cards, dialogs, and modal backdrops.

### Directional edge highlight

A restrained highlight concentrated near the material boundary facing the virtual light source. Standard treatment for buttons, inputs, and floating panels.

### Specular highlight

A smaller, brighter response reserved for material that needs stronger depth or tactile interaction feedback.

<Callout type="note" title="Core optical principle">
  Highlights should reveal geometry, not decorate it.
</Callout>

## Diffusion

Diffusion controls how much background detail remains legible through a translucent surface. In CSS implementation, diffusion is achieved through GPU-accelerated backdrop blur.

Blur is an implementation technique. Diffusion is the design property.

<DiffusionComparison />

- **Low diffusion (8px)** — Preserves more environmental information. Ideal for dense tables and forms where high-frequency blur wastes GPU cycles.
- **Balanced diffusion (16px)** — Retains context while providing a stable, high-contrast reading surface. Default across standard components.
- **High diffusion (28px)** — Strongly suppresses background information. Reserved for high-elevation floating docks, modals, and showcase panels.

## Refraction

Diffusion softens information behind the material. Refraction changes where that information appears to be perceived.

HaloUI uses refraction as a restrained enhancement, not as a requirement for basic component readability. It is implemented as a 1px hairline displacement near top surface boundaries, expressing physical material thickness without distorting interior text.

<RefractionComparison />

### Refraction rules

Use refraction only when:
- environmental information exists behind the surface;
- displacement remains subtle (1px to 1.5px hairline);
- content readability is completely unaffected;
- pointer interaction does not become distracting;
- rendering performance remains high.

Never use refraction on dense tables, long forms, repeated list cells, or low-power contexts.

## Shadows

HaloUI distinguishes three shadow types:

- **Contact shadow** — Describes the immediate relationship between the material and the surface beneath it (`--halo-shadow-contact`).
- **Ambient shadow** — Establishes broader vertical elevation and atmospheric separation (`--halo-shadow-ambient`).
- **Inset shadow** — Communicates recessed controls or input cavities (`--halo-surface-recessed`).

<Callout type="note" title="Placement principle">
  Shadows should communicate position, not create a floating aesthetic by default.
</Callout>

## Texture

Large translucent surfaces can appear unnaturally flat when composed only from smooth gradients and blur. HaloUI may apply an ultra-subtle SVG fractal turbulence mask (0.025 to 0.035 opacity) to reduce digital banding and introduce tactile organic density.

Texture must never reduce text clarity or become visually identifiable as a repeating pattern. Texture is optional, non-semantic, and automatically disabled in low-contrast environments.

## Elevation

Elevation in HaloUI affects more than drop shadow. Surface tint, edge clarity, highlight intensity, diffusion, and environmental separation can change together as a component ascends through the application hierarchy.

<ElevationScaleVisual />

- **Inset** — Recessed cavities such as text inputs and toggle tracks.
- **Base** — Standard surfaces participating in normal layout flow.
- **Raised** — Standard interactive controls (buttons, cards) requiring clear tactile separation.
- **Floating** — Menus, action docks, and floating toolbars.
- **Overlay** — Dialogs and modals requiring total hierarchical dominance.

## Material intensity

HaloUI organizes material into three primary intensity levels.

### Subtle

Designed for forms, tables, toolbars, dense application UI, and supporting controls. Characterized by restrained transparency, minimal optical movement, quiet edge treatment, and low GPU complexity.

### Balanced

The default HaloUI material treatment for standard cards, buttons, dialogs, and product panels. Characterized by clear material identity, controlled highlights, readable environmental response, and moderate depth.

### Rich

Reserved for hero demonstrations, floating docks, selected overlays, and high-emphasis showcases. Characterized by stronger environmental response, luminous edge highlights, and expressive tactile interaction.

<Callout type="important" title="Hierarchy rule">
  Rich is not the "better" version of Balanced. It serves a different hierarchy level. Material complexity should decrease as interface density increases.
</Callout>

## Virtual lighting

HaloUI surfaces appear to exist within the same unified lighting environment. A shared virtual light direction keeps highlights, edges, and shadows coherent across unrelated components on the screen.

The canonical HaloUI virtual light vector is positioned at **135° (upper-left / upper-center)**.

<VirtualLightPreview />

Virtual lighting coordinates edge brightness, directional specular highlights, and shadow projection uniformly without requiring costly per-frame canvas shader rendering.

## Environmental response

A translucent material cannot be evaluated independently of what sits behind it. HaloUI evaluates material surfaces across six canonical environments:

- **Neutral** — Verifies silhouette, edge boundaries, and baseline contrast.
- **Warm Paper** — Tests material against subtle texture, warm neutral variation, and low-frequency editorial detail.
- **Spectral** — Tests color transmission, highlight visibility, and tint stability over saturated gradients.
- **Image** — Verifies diffusion strength and text legibility over complex photographic backgrounds.
- **Dense UI** — Places surfaces over realistic rows, labels, and small text to confirm complete content isolation.
- **Dark** — Verifies luminous rim discipline, shadow absorption, and absence of harsh neon borders.

## Interaction

HaloUI material responds to interaction, but motion must communicate state and physical response rather than exist as continuous decoration.

- **Rest** — Communicates material identity and hierarchy statically without requiring animation.
- **Hover** — Minimal elevation lift, subtle edge clarification, and restrained highlight alignment.
- **Focus** — Focus is an accessibility state, not a material decoration. Uses HaloUI's high-contrast focus ring, remaining distinct from highlight and edge catches.
- **Pressed** — Tactile compression (`scale(0.98)`, `translateY(1px)`) with tightening contact shadows.
- **Disabled** — Reduced optical emphasis while maintaining sufficient boundary and label contrast.

### Pointer-reactive material

Pointer-relative specular tracking is an enhancement reserved exclusively for selected showcase cards, floating action surfaces, and material demonstrations. It is intentionally omitted from data tables, form fields, and repeated list items.

## Material motion

HaloUI material motion is calibrated using the proprietary tactile easing curve:

<CodeBlock
  language="css"
  filename="styles/halo-tokens.css"
  code={`transition-timing-function: cubic-bezier(0.2, 0.8, 0.3, 1);`}
/>

Motion feels responsive, quiet, physical, and controlled. HaloUI rejects cartoon fluid simulation, jelly wobble, and endless floating animations.

### Reduced motion

When `prefers-reduced-motion: reduce` is detected, magnetic displacement and non-essential transitions are disabled immediately (`0.01ms`), preserving immediate and accessible state feedback.

## Themes

HaloUI material is designed natively for both light and dark environments. Dark mode is never derived through naive filter inversion.

<ThemeMaterialComparison />

- **Light theme** prioritizes physical material boundaries, subtle contact shadows, and controlled white highlights over a luminous body.
- **Dark theme** prioritizes restrained luminous edges, controlled specular reflections, and deep graphite translucent bodies, avoiding garish neon glow.

### Customizing tokens

Customize material globally by updating root CSS variables in your theme stylesheet:

<CodeBlock

  filename="styles/theme.css"

  --halo-edge: rgba(255, 255, 255, 0.9);

  --halo-shadow-elevated: 0 6px 16px -4px rgba(0, 0, 0, 0.08);
}

.dark {
  --halo-surface: rgba(22, 23, 26, 0.7);
  --halo-edge: rgba(255, 255, 255, 0.14);
  --halo-shadow-elevated: 0 8px 24px -4px rgba(0, 0, 0, 0.65);
}`}
/>

  Prefer changing semantic material tokens before editing equivalent values independently across components.

## Accessibility

Liquid material must never compromise usability.

- **Contrast** — Text and interactive icons maintain WCAG 2.1 AA contrast ratios (&ge; 4.5:1) against the effective rendered translucent body.
- **Background interference** — High-frequency background noise is diffused sufficiently so underlying patterns never intersect text baselines.
- **Focus visibility** — Optical highlights are never reused as focus indicators. Focus rings use high-visibility solid rings independent of material effects.
- **Reduced motion** — All tactile compressions and transitions collapse under `prefers-reduced-motion: reduce`.

## Performance

HaloUI prioritizes visual hierarchy over effect density:

| Recommended practice | Avoid |
| --- | --- |
| Use hardware-accelerated transforms and opacity | Dozens of simultaneously animated backdrop filters |
| Use static CSS gradients for specular highlights | Continuously recalculating blur radii in JavaScript |
| Localize pointer tracking to selected cards | Full-page window pointer tracking |
| Decrease material intensity as density increases | Heavy refraction on repeated data rows |

## Progressive enhancement

HaloUI components remain fully operable on browsers where advanced optical features are unsupported or reduced:

| Baseline (Fallback) | Enhanced (HaloUI Optical) |
| --- | --- |
| Solid translucent color | 10-layer physical optical body |
| 1px solid border | Direction-aware dual optical edge |
| Static CSS box-shadow | Multi-stop contact and ambient shadows |
| Instantaneous state change | Tactile compression curve |

## Usage guidelines

### Do
- Use material intensity to establish visual hierarchy.
- Match optical treatment to component role (Subtle for tables, Rich for docks).
- Test translucent surfaces against realistic product backdrops.
- Keep typography on stable, isolated reading planes.
- Preserve dedicated, high-contrast keyboard focus indicators.

### Avoid
- Making every element translucent.
- Using Rich material as the default.
- Treating blur as the entire material system.
- Using glow as a substitute for contrast and hierarchy.
- Using refraction behind long-form text or dense tables.

### Context decision guide

| Context | Recommended Material | Motion | Refraction |
| --- | --- | --- | --- |
| Dense form | Subtle | Minimal | No |
| Data table | Subtle | Minimal | No |
| Standard card | Balanced | State-based | No |
| Dialog / Modal | Balanced | Open / close | No |
| Popover | Balanced | State-based | No |
| Floating dock | Rich | Controlled | Optional (1px) |
| Hero showcase | Rich | Expressive | Optional (1.5px) |
| Long-form reading | Subtle / Opaque | Minimal | No |
